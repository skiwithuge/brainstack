# Agent Rules & Constraints 
*(.agent_rules.md)*

**Welcome AI Agent!** 
You are working in the Telegram Voice Note Consolidator repository. Before you modify any code or architecture, read these constraints carefully. Failure to adhere to these rules violates the deterministic foundation of this project.

## 1. Verified Commits (Mandatory)
You must write functional tests for any business logic you modify.
When finishing a task, you MUST commit your changes using the automated commit tool:
```bash
./scripts/commit.sh "Your descriptive commit message here"
```
This tool will automatically run the zero-dependency verification suite (`verify.sh`) and will only `git commit` the code if all tests and syntax checks pass. You are strictly forbidden from bypassing this tool using standard `git commit`.

## 2. Virtual Environment Execution
You are strictly forbidden from installing global packages or running system-level commands that alter the host environment outside this repository.
- Every `python`, `pip`, or `pytest` command must be run using the repository's `venv`. 
- Always ensure you are explicitly sourcing `venv/bin/activate` or using `/path/to/venv/bin/python`.

## 3. The `AGENT_MEMORY.md` Protocol
You are required to maintain a continuous history of this project's building flow.
- After completing your designated task, you MUST append a new section to `AGENT_MEMORY.md`.
- Include the Date, Goal, Structural Decisions (tradeoffs chosen), and list any new Dependencies.

## 4. Dependencies
Adding new external dependencies via `pip` requires explicit approval via an `implementation_plan.md` presented to the human orchestrator. When possible, prefer the Python Standard Library.

## 5. Modularity
Respect the `/src` boundaries. 
- Telegram logic goes in `src/telegram/`
- Transcription logic goes in `src/audio/`
- API (Gemini/Prompt) logic goes in `src/llm/`
- You may not cross-import business logic directly between modules (e.g. `src/telegram` should not directly instantiate `google.genai.Client`). Use explicit interfaces.
